A simple port scanner written to practice Python. It will ask you to input an IP address and a port number, then tell you whether that port is open or closed.

-----------------------------------------------------

How to use:

Method 1: Running the script through Command Prompt
1. Download the Python script onto your computer.
2. Open Command Prompt (PowerShell) or whichever terminal you'd like to use and navigate to the folder location where you've downloaded the script.
3. Navigate to the folder where you downloaded the script.
4. Run it with the command `py .\port_scanner.py`

Method 2: Running the script through Python
1. Download the Python script onto your computer.
2. Assuming you have Python installed on your computer, simply double click the downloaded script to run it.
